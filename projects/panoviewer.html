Panoviewer

What it does

Tile-pyramid reprojection

Reprojects a giant equirectangular photo into a cube-face tile pyramid (pure Pillow engine; optional fast Hugin/nona engine) so browsers stream only what is visible.

Static, host-agnostic output

Static output under webroot/: deployable to Cloudflare Pages or any static host as-is, no build step.

Shareable deep-linked views

Every view is a shareable deep link: yaw/pitch/fov live in the address bar.

Desktop and mobile (WebGL)

Works on desktop and phones.

Repository practices

Repository practices: dev carries tests, plan docs and research tooling while main holds only the runnable subset; matching v1.0.0-alpha tags on both trees; MIT licence; .gitattributes/.gitignore hygiene; vendored viewer libraries can be re-generated rather than committed.

Evidence

  • Public repository: MIT licence; dev tree carries tests and plan docs, main the runnable subset
  • Validation ships with the repo: check_layout.py (per-level tile file checks) and smoke_serve.py (boots the server and asserts key URLs return 200)
  • End-to-end verification recorded in the README, against three sample sizes: rendering, first-paint from preview strip, zero failed tile requests, seam/pole continuity, phone touch with deep-link write-back
