Panoviewer

A local-first viewer for panoramas so large they break normal image pipelines — with the release discipline of a real project.

50,956×25,478largest image tested (~1.3 GPixel)
100k×50kdesign headroom target
0build steps needed to deploy
2tags: v1.0.0-alpha / -dev

What it does

  • Reprojects a giant equirectangular photo into a cube-face tile pyramid (pure Pillow engine; optional fast Hugin/nona engine) so browsers stream only what is visible.
  • Static output under webroot/ — deployable to Cloudflare Pages or any static host as-is, no build step.
  • Every view is a shareable deep link: yaw/pitch/fov live in the address bar.
  • Works on desktop and phones (WebGL).

Why it counts as Goal 3 evidence

This is the software-development-tools goal made visible: a dev/main branch split where main carries only what is needed to run and dev carries tests, plans and research tooling; semantic tags for both trees; MIT licence; .gitattributes/.gitignore hygiene; and a documented dependency policy (vendored viewer libs can be re-generated, not committed).
