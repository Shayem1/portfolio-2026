Why it exists

Goal 4 of the learning plan specified a narrow system: "an autonomous workflow that will scan and read spreadsheets, text files, and images … and return routinely updated database", using n8n "or equivalent". That workflow was built (Scanner-for-IBMA). But instead of importing an off-the-shelf orchestrator, everything it required was engineered from scratch on this machine — inference serving, audio, diarization, image search, video grounding — and each piece was kept as a general tool any agent can use through MCP tool doors.

Nothing here was imported as a ready-made toolkit: every component was authored, calibrated and benchmarked locally. Generic MCP servers now exist publicly; this stack differs by being local-first, calibrated to real data, and measured — every number on this page comes from a local test log or manifest.

Components (all self-built on this machine)

  • Serving engine — Strata: quantised-LLM inference on an RX 9070 XT (HIP gfx1201), OpenAI-compatible doors (/v1/chat/completions, /v1/audio/transcriptions), vision reader, geometric prompt-cache checkpoints and conversation-cache slots (bench: −9.6 % to −25.4 % re-read cost).
  • Audio grounding — whisper.cpp built from source with Zen 4 SIMD kernels (AVX512/VBMI/VNNI/BF16); one pass per recording, timestamp manifests written per transcription.
  • Speaker diarization — pure-CPU sherpa-onnx pipeline; segmentation + speaker embeddings; reproduces the published reference split exactly (4/4 turns, RTF 0.04); language-robust embedding model chosen after cross-language failure testing.
  • Image store — Tier 1: 64-bit DCT perceptual hash with SHA-256 dedupe; Tier 2: CLIP/SigLIP embedding search in SQLite with calibrated thresholds (near-duplicates ≥0.95, related scenes 0.5–0.7, cross-domain ≤0.65); Tier 2b: text→image retrieval via pruned CLIP text tower (dead-end logged: SigLIP text tower misaligns — documented, not hidden).
  • Video grounding — motion-adaptive keyframes (tile-diff thresholds with codec-noise suppression, NMS, coverage skeleton) joined to diarization turns by timestamp, so a frame carries who was speaking when.
  • Agent surface — every capability exposed through MCP tool doors and consumed daily by an OpenCode agent workflow (including the one that helped assemble this portfolio).
