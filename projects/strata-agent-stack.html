Components (off-the-shelf engines; built, tuned and assembled here)

Serving engine (Strata)

Off-the-shelf inference engine packaged for this hardware (HIP gfx1201 build) and tuned here; quantised-LLM inference on an RX 9070 XT with OpenAI-compatible serving doors written locally (/v1/chat/completions, /v1/audio/transcriptions), vision reader, geometric prompt-cache checkpoints and conversation-cache slots (bench: −9.6 % to −25.4 % re-read cost).

Audio grounding

Whisper.cpp engine built from source for this CPU with Zen 4 SIMD kernels (AVX512/VBMI/VNNI/BF16); the one-pass-per-recording flow and per-transcription timestamp manifests are integration code written here.

Speaker diarization

Sherpa-onnx segmentation and speaker-embedding models (off-the-shelf); the run scripts, cross-language model selection and turn-join logic are mine; reproduces a published reference split exactly (4/4 turns, RTF 0.04).

Image store

Core written here (64-bit DCT perceptual hash, SQLite store, calibrated thresholds: near-duplicates ≥0.95, related scenes 0.5–0.7, cross-domain ≤0.65; 235 ms scan over 200k rows). CLIP/SigLIP models are pretrained and were pruned on this machine via an ONNX graph walk into vision-only and text-only towers (SigLIP text-tower misalignment logged as a documented dead end; 18 ms text-to-image queries).

Video grounding

Selection algorithm written here (motion-adaptive keyframes, codec-noise suppression, NMS) on top of PyAV CPU decode; keyframes joined to diarization speaker turns by timestamp, so a frame carries who was speaking when (1.1 s to keyframe a 300-frame probe).

Agent surface

Every capability exposed through MCP tool doors written here, consumed daily by agent workflows (including the one that helped assemble this portfolio).

Runs with or without an agent in the loop. Whisper transcribes and translates live (any language to English); diarization separates speakers live; joined, they output multilingual multi-speaker transcripts to any downstream system. This pipeline superseded an earlier containerised translation service (archived as PF10).

Target silicon: enterprise desktops, the class of machine client workplaces actually own (10-20 core AVX-class CPUs, weak display GPUs).
